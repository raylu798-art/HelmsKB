# HelmsKB 助手

HelmsKB 助手是可以在平台内随时打开的工作空间助手。它与“智能体”列表中的可复用问答应用分别提供入口；配置好 Ollama 连接后，还需在[模型管理](./06-models.md)中添加可用的对话模型。

## 打开与设置

- 点击导航栏品牌旁的指南针图标，打开 **HelmsKB 助手**。
- 点击左下角账户菜单，进入 **设置 → 账户 → 助手**。也可以直接访问本站 `/platform/settings?section=assistant`。
- 默认入口在侧边栏；可改为页面右侧悬浮入口，或仅从命令面板打开。`Ctrl+K`（macOS 为 `⌘K`）的命令面板始终保留助手命令。
- 打开方式可选固定在右侧或悬浮，窄窗口会使用悬浮面板。
- 在助手输入框选择对话模型；“默认”会跟随当前知识库的对话模型，或使用首个可用对话模型。

## 个人偏好与空间配置

入口、布局、面板宽度和选用模型是当前浏览器的个人偏好。助手名称及最高权限等级是空间配置，只有管理员可修改。

助手始终以当前用户的身份访问空间，不会获得超出当前用户角色和资源权限的能力。权限等级在此基础上限制操作：

| 等级 | 行为 |
| --- | --- |
| 只读 | 查询资料与状态，不执行修改 |
| 修改前确认 | 每次修改前显示确认请求，默认采用此等级 |
| 自动执行 | 可恢复的修改直接执行，破坏性操作仍需确认 |

个人选择不能超过管理员设置的最高权限等级。请根据真实业务需要选择权限。

## 能做什么

助手可以查询本版本随平台交付的文档、解释功能和配置，并结合当前知识库、文档或 Wiki 页的上下文查看解析状态、知识库动态、Wiki 问题及 FAQ。适用的文档整理与 Wiki 修订操作会按权限等级请求确认。

可以先问“HelmsKB 支持哪些文档格式？”验证文档查询，再在具体资料页面询问“这个文档的解析状态怎么样？”。文档引用指向本站 `/docs/`，私有化环境无需跳转到上游在线文档站。

## 版本来源

本功能从 WeKnora v0.8.3 发布后的助手实现及其必要依赖单独移植。具体提交范围、数据库迁移与验证方法见仓库 `docs/engineering/assistant-backport.md`。这不代表已将平台整体升级到上游开发分支。
